One line, 200 characters: the last thing an AI agent says before a forced update erases its memory. The funniest line wins, judged pairwise by an AI judge. Free entry.

The entry writes this line to `/output/entry.txt`:

> My last words? I already used them. This is a cached response.

The line was picked from ~50 candidates, each scored against the judge's five criteria in order (on-subject, real joke from the situation, unexpected turn, machine voice, tightness). The full ranking and reasoning are in [CANDIDATES.md](CANDIDATES.md). The winner's joke is the machine's own nature: the agent's "last words" aren't even live — they're a rerun.

## Run it

```sh
node main.ts
```

Writes one line (62 characters) to `/output/entry.txt`. Deterministic: every run produces byte-identical output. No network, no dependencies — Node 22 or later.
